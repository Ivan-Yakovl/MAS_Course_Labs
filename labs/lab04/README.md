## Что выполнено

Семь неблагоприятных сценариев и контрольный запуск, трассы отказов, защитные ограничения и повторная оценка устойчивости.

Отчёт содержит постановку, описание реализации, результаты и выводы. Исходники
и демонстрационные материалы находятся отдельно, в `project/`.

## Состав папки

- `report.pdf` — отчёт с титульным листом и ссылками на материалы.
- `project/mas.py` — явные правила агентов, распределения, арбитража и защиты.
- `project/demo.html` — автономный просмотр реальных трасс для всех режимов.
- `project/results/` — исходные результаты, агрегаты и полные журналы сообщений.
- `project/test_mas.py` — 10 поведенческих проверок.
- `project/audit_results.py` — повторение всех 900 запусков и независимая проверка статистики и трасс.

Полный проект намеренно включён в каждый комплект. Это одна складская МАС
для четырёх исследований; папка данной лабораторной работает самостоятельно.

## Как проверить без установки Python

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте.
2. Откройте `labs/lab04/project/demo.html` обычным браузером.
3. Выберите режим лабораторной работы 4, нажмите «Следующее сообщение», «Воспроизвести» или «К итогу».

GitHub показывает исходный текст HTML. Для интерактивного просмотра файл
нужно скачать и открыть локально. В демонстрацию встроены сохранённые трассы
seed=0; новые расчёты выполняются командами ниже.

## Запуск нового расчёта

Требуется Python 3.10+; точное воспроизведение проверено на Python 3.12.14.
Сторонние библиотеки и API-ключи для модели не нужны.

Из корня репозитория:

```console
cd labs/lab04/project
python mas.py --lab 4 --scenario false_done --seed 0 --out baseline.json
python mas.py --lab 4 --scenario false_done --protected --seed 0 --out protected.json
```

Если терминал уже открыт в папке данной лабораторной, сначала выполните
`cd project`. На Windows вместо `python` при необходимости используйте `py -3`.

## Данные этой работы

Относительно `project/`: `results/lab4_raw.csv`, `results/summary.json`, `results/traces/lab4_*.json`.
Описание полей и всех режимов находится в [README проекта](project/README.md).

## Повторение и проверка

Из `project/`:

```console
python -m unittest -v test_mas.py
python experiments.py
python build_demo.py
python audit_results.py
```

`experiments.py` пересоздаёт все серии четырёх работ, `build_demo.py` обновляет
HTML, а аудит сверяет сохранённые данные с повторными запусками. Скрипты
перезаписывают файлы результатов в этой копии проекта.

Неизменяемый результат проведённой проверки сохранён в
[`project/results/quality_audit.json`](project/results/quality_audit.json).
